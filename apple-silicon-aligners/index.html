Hill-climbing genome aligners on Apple Silicon

WGS Extract spends most of a genome's time in the aligner. Over six days, AI agents rebuilt BWA, BWA-MEM2, bwa-mem3 and minimap2 for Apple Silicon and its GPU, one measured step at a time. Every version had to write exactly the same alignments as upstream, and only kept a change if it was faster.

Get the aligners

Free and open source, for Apple Silicon Macs on macOS 13 or later. They write the same alignments as upstream BWA, BWA-MEM2, bwa-mem3 and minimap2.

Use them

From the aligner README. Download with gh (or curl) rather than a browser, so Gatekeeper's quarantine flag doesn't stop these ad-hoc-signed builds.

  1. Download the latest build and check it

    Continue only if every archive reports OK.

    mkdir wgse-aligners && cd wgse-aligners
gh release download macos-aligners-14 -R WGSExtract/wgsextract-cli
gh release view macos-aligners-14 -R WGSExtract/wgsextract-cli --json assets \
  --jq '.assets[] | "\(.digest | ltrimstr("sha256:"))  \(.name)"' |
  shasum -a 256 -c

  2. Unpack and put them on PATH

    Add the export to your shell profile to keep it.

    for archive in wgse-*-macos-arm64.tar.gz; do tar -xzf "$archive"; done
for dir in wgse-*-macos-arm64; do PATH="$PWD/$dir/bin:$PATH"; done
export PATH

  3. Run one directly

    Same commands and index files as upstream; --metal (experimental) runs part of the work on the GPU.

    wgse-bwa mem -t 9 hs38.fa R1.fastq.gz R2.fastq.gz > out.sam
wgse-bwa --metal mem -t 9 hs38.fa R1.fastq.gz R2.fastq.gz > out.sam

  4. Or let WGS Extract use them

    When they're on PATH, WGS Extract's align and realign run them in place of bwa, bwa-mem2 and minimap2.

    wgsextract align --r1 sample_R1.fastq.gz --r2 sample_R2.fastq.gz --ref hs38.fa
