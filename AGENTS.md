# Agent notes

- This site is public. Only list public repositories, and check every
  screenshot for personal data (names, emails, hostnames, home paths, health
  or genetic data) before committing it.
- `data/projects.json` is the hand-written source of truth. `data/stats.json` is
  generated by `scripts/update_stats.py`; never edit it by hand.
- After any change, run `python3 scripts/update_stats.py` (when projects were
  added) and `python3 scripts/check.py`, then preview the page with
  `python3 -m http.server` and look at it before pushing.
- Screenshots are WebP, at most 1600 px wide, stored in `screenshots/<project-id>/`,
  and every file must be referenced from `data/projects.json`.
- Keep it a plain static site with no build step or dependencies.
