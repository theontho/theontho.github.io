November 2026: the GUI shootout, again

In May 2026 AI agents built the same desktop app, GUI for CLI running the real WGS Extract bundle, on about 30 UI toolkits. Six months on, I'm rerunning it with a newer model: one agent per toolkit, from scratch, on 30 toolkits, mostly for the Linux desktop, followed by a Windows pass. This page updates as each one lands.

How it's run

  • From scratch. Each toolkit is built by one agent that may not read the May implementations, their git history or the May write-up. It works only in its own folder.
  • Same app, same bundle. Every build loads the WGS Extract bundle from disk at runtime: pages, controls, strings in 22 languages, data-source scripts, actions and setup steps. Native windows with real controls; embedding the WebUI is not allowed.
  • Nine checks, in priority order: bundle loading, sidebar, page rendering, localisation, data sources, actions with streamed output and cancel, setup, saved config, and polish. Each agent marks them done, partial or missing.
  • Linux under Xvfb at 1280×800. One shared harness captures every screenshot. Apps print a GFC_READY marker once the sidebar and first page are drawn; ready time and memory are taken there.
  • Claude Opus 5.5 at high effort in OpenCode, four agents at a time, with a supervisor agent handing out the queue. Windows builds follow on an Azure VM.
  • Rated by hand at the end. The agents' self-ratings come first, the supervisor rates the screenshots, and I give the final owner rating once all of them are in.
